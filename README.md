## Guide for my fellow contributors:
Want to join me updating this repository? Here are the steps to do so:
1. On your PC, create a folder
2. Open your terminal in this folder (usually through right click, click option "Open in Terminal"
3. Type this on your terminal:
   ```bash
   git clone https://github.com/ExoticsForth/Art_Gallery_Bootstrap_Website
   ```
4. This will create a folder for your copy of this repository.

   **Alternatively, you can instead use the folder you created as the location of the repository files by adding a space and a dot (` .`) after the command
   ```bash
   git clone https://github.com/ExoticsForth/Art_Gallery_Bootstrap_Website .
   ```

5. Open the project inside your chosen code editor (Visual Studio Code and the likes)
6. Create your own branch by clicking ``main`` with the branch icon on its left
7. Name your branch either by your name (ex. ``mupada-dev``) or by the features you want to implement (ex. ``color-palette``)



## Creating your updates/progress
As a standard in web development, we will follow a step-by-step procedure in order to improve our code.

*Note for future employers viewing this project: we do not aim making issues and pull request here too formal and intimidate code development. This is for practice in collaborative development only.*


### Part 1 - Github - Creating an Issue
1. In this repository, navigate to the `Issue` tab.
2. Click ``New Issue``
3. Write your title describing what issue or enhancement you want to implement. (ex. "Improve mobile responsiveness of the website")
4. In the body, write a short summary ("We need to ... because ... "). 
5. Create a checklist of what must happen for the issue to be deemed resolved.
6. Click ``Create``


### Part 2 - Code Editor - Implementing your feature
1. Ensure you are on a separate branch from ``main``.
2. Pull from main first. Either from settings of your code editor or running the following command in your code editor terminal:
```bash
git pull origin main
```
3. If merge conflict occurs, notify me and I'll help
4. Implement your changes. Every significant change - do a commit.


### Part 3 - Code Editor - Commits
1. Open your Git Panel in your Code Editor.
2. Label your changes. Conventional commits are preferable. Example: "``feat: add new page for news article``"
    
    **View this as your prefix guide: https://www.conventionalcommits.org/en/v1.0.0/#specification:~:text=The%20commit%20contains,parse%20arrays.
3. Press ``commit``
4. Press ``push`` with the arrow up button
5. Pull from main again then continue
